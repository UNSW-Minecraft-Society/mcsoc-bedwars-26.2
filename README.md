# bedwars plugin

## Commands:
- `bedwars`
  - `reload (OP)`
  - reloads the plugin config

## Commands

`/bedwars generator add <type> [<position>]`
- adds a specific generator at position, or players position if not speecified

`/bedwars generator remove <position>`
